# Codex に雑用を回す

ChatGPT プランの枠が余っているので、雑用は Codex（下請け）に回して Claude の使用量を抑える。
設計: `~/dev/black_note/docs/superpowers/specs/2026-11-05-codex-delegate-design.md`

## 回すか決める

得になるのは「Codex が読む量に比べて、答えが十分の一以下」の時だけ。

| 回す | 回さない |
|---|---|
| ログ・メモ・文書の要約 | 書き込み・削除がある仕事 |
| ファイル探し、「どこに書いてある？」 | 1〜2ファイルで済む仕事（1回40秒ほどかかる） |
| 文章の下書き | 正確さが命の仕事（お金・本番・削除の判断） |
| セカンドオピニオン | HIBIKI（unsou-system） |

ボスが「Codex で」と言った時も、損になるなら一言そう伝えてから自分でやる。

## 頼み方

```sh
~/.claude/skills/codex/run.sh <対象フォルダ> "<依頼文>" [字数=800]
```

- 依頼文は1つの仕事に絞り、何を返してほしいかを書く（例: 「箇条書きで」「ファイル名:行 を添えて」）
- 字数はなるべく小さくする。答えはそのまま Claude の使用量になる
- Bash の timeout は 320000 にする（run.sh 自身が5分で打ち切る）
- `.env` 等を読まない決まりと字数の決まりは run.sh が毎回付けるので、依頼文に書かなくてよい

## 受け取った後

- 返事に「（Codex に回しました）」と添える
- 確かめるために原本を読み直さない（二重払いになる）。怪しい所は「怪しい」とそのまま伝える
- 失敗した時（終了コード 0 以外）は自分で引き取り、「Codex が使えなかったので自分でやりました」と書く
  - 2: HIBIKI なので断った / 3: Codex が無い / 4: 時間切れ / その他: ログイン切れ・枠切れ・エラー
